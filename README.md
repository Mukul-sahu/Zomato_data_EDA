# Zomato_data_EDA
This project explores the Zomato dataset to uncover insights about restaurants across various countries and cities. Through data cleaning, transformation, and visualization, we analyze trends in ratings, cuisine popularity, and service availability.


## 🛠️ Tools & Libraries

- Python 
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook


## 📈 Key Insights

- India has the highest number of listed restaurants.
- North Indian, Chinese, and Fast Food are among the most popular cuisines.
- A significant number of restaurants have not been rated.
- Online delivery is only available in India and UAE (in some restaurants).
- Price range varies heavily across countries and cities (Depending on currency used).
